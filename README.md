# 💱 Currency Converter

A simple web‑based currency converter built with **HTML, CSS, and JavaScript**.  

---

##  Features
- Convert between 200+ currencies (including crypto & metals).
- Daily updated exchange rates.
- Country flags displayed dynamically using [FlagsAPI](https://flagsapi.com).
- Responsive and user‑friendly interface.
---

## 📂 Project Structure
- `index.html` → Main UI layout.
- `style.css` → Styling for the converter.
- `app.js` → Core logic (dropdowns, API calls, conversion).
- `codes.js` → Currency → Country mapping for flags.
